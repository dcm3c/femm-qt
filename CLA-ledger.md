# Solver contributor agreements on file

Contributor License Agreement, [CLA-solvers-entity.md](CLA-solvers-entity.md),
and which version. Their designated contributors may submit solver changes on
the organization's behalf. The signed agreements themselves are kept by the
maintainer and are not published.

Individual contributors accept [CLA-solvers.md](CLA-solvers.md) in their pull
request; each acceptance is recorded, with name, GitHub username and version,
in the commit that applies the change, so individuals are not listed here.
