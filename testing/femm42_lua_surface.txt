# FEMM 4.2's documented Lua script surface -- luafemm's compatibility target.
#
# Every name FEMM 4.2 makes callable from a script: the commands it registers
# with lua_register() across its femm/*.cpp, plus the functions defined in its
# init.lua. Checked in because FEMM 4.2's sources are not part of this
# repository -- the same reason the Original-FEMM goldens beside this file are.
#
# This is a FLAT list on purpose. An earlier version split it into "wrapped"
# and "absent" sections, but those were computed from femm.lua itself, so the
# check was circular: a command missing on the day the file was written would
# have been filed under "absent" and never reported again. The list now says
# only what FEMM 4.2 offers. Whether a name is reachable is decided at test
# time by asking the ENGINE, which is the same method DocDriftTest uses on the
# manuals -- you cannot classify a command by its name.
#
# EXCLUDED: the snake_case aliases. FEMM 4.2 registered both spellings and only
# the compact one was ever documented -- and not only for the xx_ commands:
# new_document, show_console and four more are globals with the same shape. The
# rule that catches every case is "drop a name whose underscores removed give
# another name in this list", which is how those six were found after a filter
# written only for the xx_ prefix let them through.
#
# Regenerate only from FEMM 4.2's sources, never from this binding.
